# SEO Checklist

## Content

- Write original content.
- Use H1 only once.
- Include keywords naturally.
- Answer user intent.

## Technical SEO

- Enable HTTPS.
- Compress images.
- Use lazy loading.
- Generate sitemap.xml.
- Add robots.txt.

## Performance

- Optimize Core Web Vitals.
- Reduce JavaScript.
- Minimize CSS.

## Metadata

Every page should contain:

- title
- meta description
- canonical URL

## Internal Linking

Every important page should have at least three internal links.

## Structured Data

Use JSON-LD whenever possible.
